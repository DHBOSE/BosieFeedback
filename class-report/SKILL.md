# 课堂报告生成器（Class Report Generator）

将一段「课程速览 + 课程纪要」自动整理成结构化的 **课堂报告**，同时产出 **Word（.docx）** 与 **PDF（.pdf）** 两个版本，并在文末**预留知识点脑图的空白位置**（不生成脑图图片，由使用者自行添加）。

## 何时调用

- 用户粘贴/提供了两块内容：「**课程速览**」（带时间戳的课堂分段小结）与「**课程纪要**」（课堂逐字稿/纪要摘要）；
- 并要求「生成课堂报告 / 整理成报告 / 输出 Word 和 PDF 课堂报告」。

## 硬性规则（必须遵守）

1. **封面固定五要素**：标题、学科、授课形式、主讲内容、报告日期。**不得**出现「学生升学目标」等个性化字段。
2. **禁止任何 AI 水印**：全文**不得**出现「由 AI 生成 / AI 辅助生成 / 本报告由 AI 辅助生成 · 仅供参考」等字样或描述。生成后**必须校验** docx 内无 `word/header*.xml`、`footer*.xml`、`*watermark*` 部件（WPS Writer 打开/保存时可能自动注入「AI 生成」水印到 `header_watermark.xml`，属外部污染，非本 skill 产出；交付前打开 zip 检查 `namelist()`）。
3. **课堂内容要精简**：只写核心结论概览，不铺陈；**课程纪要须大幅度保留原文**（仅删除与学科无关的内容），单列为「课程纪要」供学生复习（标题不带“复习版·完整保留”字样）。
4. **剔除与学科学习无关的内容**：升学目标/竞争焦虑、AI 工具闲聊、老师个人趣闻、其它学科话题等一律不要。
5. **课堂作业须单列**：从课程纪要「作业布置」中提取作业范围与要求，单列为「课堂作业」板块（含答题规范提醒）；课程纪要正文不重复罗列作业。
6. **知识点脑图留空**：**不生成任何脑图图片**，仅在文末预留空白位置，由使用者自行添加脑图。
7. **标题与合适处加 emoji**：一级/二级标题前统一加 emoji 提升生动性，正文 bullet 的标签可适当点缀；不冗余堆砌。
8. **必须含「课堂表现」**：作为第二部分，分「👍 优点」「🔧 待改进」两段，客观阐述本节课的优缺点。
9. **封面信息行用无框线表格**：学科/授课形式/主讲内容/报告日期四项，用无框线两列表格（标签右对齐、值左对齐、整表居中）排版更整齐；值单元格按内容长度自动缩小字号、**不换行**。

## 交付物（固定结构，顺序如下）

1. **封面**：顶部小字「🎓 课堂报告」、主标题、副标题、分隔线、信息行（标题/学科/授课形式/主讲内容/报告日期，用**无框线表格**排版）。无升学目标、无 AI 水印。
2. **📚 课堂内容**：精简概览，4~6 条核心结论 bullet。
3. **🌟 课堂表现**：分「👍 优点」「🔧 待改进」两段，阐述本节课优缺点。
4. **📝 课程纪要**：按知识点分小节（小节标题加 emoji），尽量保留原始纪要文字与细节，仅删学科无关内容。
5. **🏆 课程收获**：6~8 条，采用「标签：说明」bullet。
6. **📋 课堂作业**：从纪要「作业布置」提取作业范围 + 答题规范提醒。
7. **⚠️ 易错分析**：提炼易错点，每条给出「正确理解/纠正」。
8. **💡 学习建议**：可操作、落地的学科学习方法。
9. **🧠 知识点脑图**：仅预留空白位置（不生成脑图图片），附提示语请自行添加。

## 依赖与工具链

- Python 3、`python-docx`（生成 docx）。脑图不生成图片，无需 `matplotlib`/`Pillow`。
- PDF 转换二选一：
  - **推荐**：Microsoft Word COM（`SaveAs2(..., 17)`，17 = wdFormatPDF），见 `templates/docx2pdf.ps1`；
  - 备选：LibreOffice `soffice --headless --nologo --norestore --convert-to pdf`（部分 Windows 会话下报 DLL 初始化失败时改用 Word COM）。

## 执行流程

0. **环境自检**：确认 Python、python-docx 可用；确认 `WINWORD.EXE` 或 `soffice` 可用于转 PDF。
1. **解析输入**：从「课程速览」提取〔时间点 → 知识点主题 → 讲解要点〕；从「课程纪要」提取〔核心结论、关键数据、实验、推导、例题、作业、易错点、学习建议〕。
2. **生成 Word**：复制 `templates/gen_report.py`，填充 `META` 与正文（用 `heading()` / `para()` / `bullet()`，标题带 emoji），写好「课程纪要」「课堂表现」「课堂作业」，封面信息行用无框线表格，「知识点脑图」只预留空白位置（不生成图片），运行得 `report.docx`。
3. **转 PDF**：运行 `templates/docx2pdf.ps1`（或 LibreOffice 命令）转 `report.pdf`。
4. **重命名交付**：用 Python 将文件重命名为「学科-章节-主题-课堂报告.docx/.pdf」，向用户提供文件链接。

## 知识点脑图（预留空白位置）

- **不生成任何脑图图片**（无根节点、无空白分支框）。
- 在「🧠 知识点脑图」标题下，放一句居中提示（浅灰小字），再预留约三分之二页空白（若干空段落），由使用者自行绘制或插入脑图。

## 报告版式规范

- 页面：A4（210×297mm），边距约 2.2cm。
- 字体：正文 11pt，标题 16/13/11.5pt；中文显式设置 `eastAsia=Microsoft YaHei`。
- 配色：标题深青 `#216873`、强调标签暖红 `#E65A5A`、正文深灰 `#333`、注释浅灰 `#787878`。
- 封面全部水平居中，信息行用无框线表格排版；一级标题下加浅色横线（`w:pBdr`）；不生成目录页。
- **emoji**：一级/二级标题统一前置 emoji（见交付物），正文 bullet 的标签可点缀，不堆砌。

## 内容写作要点

- **课堂内容**：精简，只给结论概览 + 一句主线说明，细节全部交给「课程纪要」。
- **课堂表现**：客观、具体，分「👍 优点」「🔧 待改进」两段；就本课专注度、概念辨析、答题规范等方面展开，不空泛、不过度夸赞。
- **课程纪要**：**大幅度保留原文**，按知识点分小节（H2，标题加 emoji），用 bullet 逐条保留细节；只删学科无关内容，不自行精简、不丢关键数据/实验/推导。
- **课堂作业**：从纪要「作业布置」提取作业范围（如书名 + 页码范围），并附答题规范提醒；不编造、不夸大作业量。
- **易错分析**：每条「① 误区标签 + 正确理解」，突出易错字、易混概念、易漏步骤。
- **学习建议**：落到具体动作；**不写**与学科学习无关的『放松心态/心理建设/家长沟通』等内容。
- **脑图**：不生成图片，只预留空白位置；导语提示「请自行添加脑图」。
- **输出语言**：与用户输入一致（默认中文）。

## 示例（schema 参考，非隐私数据）

初中物理「声现象 · 声音是什么」：封面主标题「声音是什么」、副标题「—— 声现象（第一章）」，信息行用无框线表格；课堂内容 5 条核心结论；课堂表现 = 优点 3 条（专注度高 / 概念辨析准 / 思路清晰）+ 待改进 3 条（回声计算 / 答题规范 / 关键数据）；课程纪要按「物理学科初探 / 声音的产生 / 声音的传播 / 声速与回声 / 声音的能量与应用 / 例题演练与答题规范」六小节保留原始细节（标题不带“复习版”）；课程收获 6 条、课堂作业 3 条、易错分析 8 条、学习建议 7 条；知识点脑图只预留空白位置（不生成图片）。其余课程照此抽象。
